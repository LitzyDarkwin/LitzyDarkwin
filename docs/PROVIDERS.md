# PROVIDERS — external/addon contracts

All external data is untrusted: validate, normalize, attribute, timestamp.

## Market — TSM public data (primary)
- Base: `https://public-data.tradeskillmaster.com/{gameType}/{region}/…`
  (verified 2026-09-09 against the official column docs).
- Retail EU datasets consumed:
  - `retail/eu/commodities.csv` (~every 3 h):
    `itemId,name,marketValue,minBuyout,recent,historical,updatedAt`
  - `retail/eu/region/items.csv` (~daily):
    `itemId,name,marketValue,historical,avgSalePrice,saleRate,soldPerDay,updatedAt`
  - All prices in copper; `updatedAt` is ISO-8601 UTC and identical for every
    row in a file (upstream scan time, not fetch time).
- No API key, no rate limits (public static files). Record `fetched_at` plus
  the provider `updatedAt`; never assume cadence.
- Core (`market.rs`): dependency-free CSV + strict-header parsing (bad header =
  loud failure, provider format drift is never silent); malformed rows skipped
  + counted. Ingest is transactional per dataset; the old cache survives any
  failure. Region stats never touch the live columns.
- Fetching in the shell (`refresh_market`, reqwest blocking, 60 s timeout):
  both files fetched before any DB write; partial success reported per dataset.
- Fallback chain: fresh cache → stale cache (penalized) → Unknown (explicit risk).

## Atlas seed data — bundled provider
- `crates/core/src/seed/atlas.json` (generated by `scripts/gen-seed.py`, fixed seed):
  expansions/continents/zones/resources + representative node priors for initial
  mining/herbalism zones. Source attribution: `seed`.
- Seed caveats: node priors are illustrative scatter, not surveyed data; zone
  `map_id` values were included best-effort for stable Retail zones and must be
  re-verified against the live client before release (see R2 in PROGRESS.md).
- Replaceable: future providers (community DB, user CSV import) implement the same
  `AtlasProvider` trait and normalize into canonical entities.

## Addon bridge — GatherOptimizer SavedVariables
- File: `<WoW>/_retail_/WTF/Account/<ACCT>/SavedVariables/GatherOptimizer.lua`
- Lua table `GatherOptimizerDB` with `schemaVersion`, `sessions[]`, `observations[]`,
  `export { version, exportedAt }`. Parsed by core's Lua-subset parser (`lua.rs`).
- Version mismatch → structured `BridgeError::SchemaMismatch { found, supported }`
  with user guidance, never silent mis-parse.

## Optional in-game integrations (feature-detected, never required)
- **TomTom**: `TomTom:AddWaypoint(...)`, `TomTom:SetCrazyArrow(...)` if global exists.
- **GatherMate2**: show/hide node icons via its public API only when `GatherMate2`
  loads; our data never depends on its internals.
- **Routes**: foreground route drawing via its public API when present; else our
  waypoint list still works standalone.
- All calls wrapped in `pcall`; absence only disables that adapter (`status` shown).

## Desktop → addon route transfer — GO1 import string (concrete, Phase 1)
- Format: `GO1.<mapID>.<n>.<coords>.<check>`; coords = per-waypoint `XXXYYY`
  decimal triplets (`floor(x*10)` clamped to 000..999, 0.1 map-unit precision);
  check = weighted digit sum mod 997, zero-padded to 3.
- Example: `GO1.2346.2.042137500500.123`. Max 40 waypoints (addon cap).
- Implemented in `addon/GatherOptimizer/Bridge.lua` (`EncodeRoute`/
  `DecodeRouteString`); desktop encodes via `export_route_string` (Phase 6).
